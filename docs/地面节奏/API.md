### 算法

地面坑 = 最下面两行（`h-1`、`h-2`）同一列都是空格；只处理列 `[8, w-12]` 内的坑。随机数：`Random(world * 7919 + level * 131 + 17)`。响度：`e(x) = SongProfile.levelEnergyAt(world, level, x / w)`。

1. 收集现有的坑（起点、宽度），记 n = 数量；n < 3 时跳过第 2–4 步，只做第 5 步。
2. **丢弃**：每个坑以 `0.5 + 0.5 * e(起点)` 的概率保留，否则填平（两行写 `#`）；保留的坑不能少于 `ceil(0.6 * n)`（用完保留名额后剩下的都保留）。
3. **挪动**：每个保留的坑起点加 `-2..+2` 的随机偏移，新位置夹在 `[8, w-12]`，并且与前一个坑的终点（起点 + 宽度）至少隔 4 格，否则保持原位。挪动 = 先填平原来的格子，再在新位置挖。
4. **宽度**：每个坑以 35% 的概率改成 1 格宽，否则 2 格宽。
5. **补坑**：在 `e ≥ 0.7` 的位置，扫描每个 12 列窗口，窗口内（含两侧 6 列）没有坑，则以 50% 的概率在窗口中心挖一个 1–2 格宽的坑；全关补的坑数 ≤ `floor(0.3 * n)`（n = 步骤 1 的数量；n < 3 时上限为 1）。
6. **双坑**：对每个保留的坑以 25% 的概率，在其终点后空 2 格实地的位置再挖一个 1–2 格宽的坑（要求右侧到下一个坑至少 4 格、不越过 `w-12`）。

全程不动其他行；挖坑 = 最下面两行写空格，填平 = 写 `#`。起点 `2`、终点附近 `w-5..w-1` 的地面不动。

### 最终安全与节奏校正

全部场景、检查点及平台放置完成后，只填平已有地面坑：消除检查点正下方的坑与检查点附近不安全的连续跳坑；响度低于 0.4 的非双坑可被填平，双坑优先保留。最后修复连续等距、宽度单一及间距种类不足的情况。该步骤不新增坑，不更改检查点或碰撞规则；初始保留率是重排阶段的约束，后续安全修复可能进一步填坑。
