# 手机竖屏遮挡修复

## 需求

手机竖屏打开网页时，游戏被旋转成横屏显示，顶部提示和 Boss 血条几乎占满一整条，把场景和主角挡住。

- **M1 Boss 血条紧凑**：`_BossHpBar` 改为公开的 `BossHpBar`（`lib/ui/play_page.dart`），单行布局（状态文字、进度条、`hp/maxHp` 同排），居中，最大宽度 260、高度 ≤ 40，背景透明度 0.6；不再随 HUD 列拉满整行。文案和颜色规则不变。
- **M2 竖屏提示自动淡出**：`GameViewport` 的“横置手机或加宽窗口”提示显示 4 秒后淡出（`AnimatedOpacity`，300 毫秒，淡出后仍在树里但不可见），不拦截点击。`showHint == false` 时一直不显示。

## 验收（`test/mobile_hud_test.dart`）

- BossHpBar 在 800 宽的约束里：渲染宽度 ≤ 260、高度 ≤ 40；含状态文字和 `hp / maxHp` 数字；狂暴时文字为“Boss 狂暴中”。
- 竖屏（400×800）里 GameViewport：开始提示不透明度为 1；过 4.5 秒后不透明度为 0；横屏里没有提示。
- 现有全部测试继续通过（尤其 `game_viewport_test.dart`、`touch_controls_test.dart`）。

## 不做

不改物理、关卡、触控按键布局（触控键本来就按可用宽度缩放）。
