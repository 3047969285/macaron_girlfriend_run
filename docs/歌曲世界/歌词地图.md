# 歌词地图

## 产品需求说明书

普通关卡不再只用节拍和响度组织场景：每首歌按歌词内容设计可辨认的地点和情绪推进，场景要出现在玩家行进路线附近，并和可跳跃的平台组合对应。六首歌分别使用校园与雨中街道、白马的旅途与关隘、镜中倒影与距离、心跳与相遇、钟点与城市回忆、夜路与路灯等意象；同一首歌的不同关卡分段变化。场景表达是对歌曲的视觉诠释，不展示歌词原文，也不宣称画面与实时唱词同步。保持现有地面路线、坑位、碰撞安全和通关能力。

素材以音频文件的歌手信息区分同名歌曲。设计参考：[《素颜》歌曲介绍](https://music.douban.com/subject/5064190/)、[《身骑白马》歌曲背景](https://www.newton.com.tw/wiki/%E8%BA%AB%E9%A8%8E%E7%99%BD%E9%A6%AC)、[《谁》](https://www.mulanci.org/lyric/sl224377/)、[《静悄悄》](https://www.joox.com/my-zh_cn/single/%2BT42zfSul9sRA4%2BY9IYxQg%3D%3D)、[《5:20AM》](https://music-tw.line.me/track/7583921001)、[《Lost》](https://chinesemusicwiki.com/lost-man-shuke-jony-j/)。

## 接口文档

`LyricWorld.chapterFor` 按歌曲及关卡取得意象，场景规划根据各章节的优先类型调整现有平台组合，地标与已放置的平台位置对应。未制作逐句歌词时间轴或逐关手工关卡；地标不增加碰撞体，现有平台负责跳跃路线。不修改存档格式。

## 测试

覆盖六首歌的意象与关卡推进、场景与平台位置对应、不同歌曲绘制结果有差异；全套关卡通关机器人与现有测试继续通过。执行 `flutter test` 和 `dart analyze lib test`。

## 可玩的歌词场景

### 产品需求说明书

为六首歌各设计可跳跃的主题路线，分别表现旧街屋檐、白马途中的三关、倒影、靠近的心跳、城市时钟和夜行归路。路线使用真实可站立平台与奖励，融入普通关的上层场景，而不是只有背景图。地面及坑位不变；故事路线必须通过原有占位、弹簧通道和可达性校验，空间不足时回退既有场景。不同章节至少有路线方向或形状变化，不承诺随唱词逐句同步。

当前九个世界的 99 关中有 76 关成功放入歌词路线，其余 23 关沿用安全回退场景；每个世界的三个章节均至少出现一次。这个覆盖率不代表 99 关都已完成逐关手工设计。

### 接口文档

场景记录提供可选的歌词路线标识；没有成功放置时不标记。关卡数据、存档、碰撞和音乐播放接口不变。

### 测试

遍历全部普通关：六首歌都必须出现可站立的歌词路线；成功场景里的平台必须真实写入关卡，前后两个章节必须呈现不同路线；地面行与基础关卡保持一致。保留全套可达性及通关机器人测试。
