# 产品需求

游戏内平台和地面显示当前歌曲的同步歌词；人物移动不影响歌词进度，暂停和切歌按实际播放器状态更新。移除素颜世界平台上的信封纹样。首次联网取得数据后缓存，供同一设备离线使用。

# 接口

歌曲进度来自音乐播放器事件；按歌曲匹配 LRCLIB 的同步记录，解析 LRC 时间轴。当前六首音频以歌曲名称、歌手及文件时长匹配；《谁》候选版本比对应录音的另一份时间轴约晚 2.96 秒，显示时应用该偏移。数据缺失或网络失败时不显示猜测歌词，可在下次进入关卡时重试。

# 测试

验证 LRC 时间解析、空行、偏移、缓存与重试，验证播放、暂停和切歌时的进度；运行完整 flutter test 与 dart analyze，并在浏览器实际检查歌词加载和显示。
