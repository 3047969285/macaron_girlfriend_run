# 产品需求说明书

1. 每个世界的普通关、Boss 关和歌曲深处均循环播放该世界的歌曲；同一首歌跨关、重试和重新进入时从上次位置继续，不被道具背景曲覆盖。
2. 《身骑白马》首次播放从 33 秒开始，歌曲循环时也跳过此前前奏；已保存的有效位置优先。
3. 退出或暂停时保存当前进度，播放时每 3 秒保存一次，重新启动应用后恢复；暂停和系统后台不偷偷继续播放。
4. 网页自动播放被拦截时，玩家首次点击或按键重试真实歌曲；失败不得误认为已经成功播放或切成无关的合成曲。
5. 音量设置为零时暂停，重新打开时可接着播放。音效不影响歌曲。

《身骑白马》本地文件长约 313 秒；参考该版本的[歌曲时间轴](https://www.kugou.com/song-36/14187e.html)，人声约从 37 秒开始，因此从 33 秒进入，保留约 4 秒铺垫。
