# 产品需求说明书：按钮精简（v1.6）

## 1. 背景

1.5.0 版功能齐全，但入口和按钮堆得多，手机上尤其明显：

- 首页有 8 个入口，其中「iPhone 版」弹窗是给开发者看的部署说明（运行 .bat、拖到 netlify），玩家用不上。
- 游戏页常驻 14 个控件。右上角 6 枚技能小芯片（字号 12，在拇指够不到的位置），和右下角「技能」大按钮重复。
- 退出关卡有两个入口（左上 ← 和暂停菜单「退出选关」），走的是同一个确认框。
- 设置里「操作音效」开关 + 「音效音量」滑块、「背景音乐」开关 + 「音乐音量」滑块，各自是两种方式做同一件事。
- 「帧率」四档只在 Android 有效，iOS 和网页上点了没反应。
- 商店「穿戴中」按钮看起来能点，点了什么也不发生。
- 新手教程和暂停菜单只写键盘按键，触屏玩家看不懂。
- **Bug**：从首页「继续冒险」进关后，过关弹窗的「选关」和暂停菜单的「退出选关」都回到首页，而不是选关地图；选关地图每次都从第 1 个世界打开。

## 2. 目标

1. 少按钮、不少能力：玩家能做的事一件不少，只是入口更少、位置更顺手。
2. 触屏玩家和键盘玩家各看到适合自己的按钮和说明。
3. 「选关」一定去选关地图，而且停在当前世界。

不做（留给后续版本）：技能按世界解锁、重试加确认框、角色外观并入商店、任何关卡和数值改动。

## 3. 名词

- **输入模式**：`触屏` 或 `键盘`。进入游戏页时按平台定初值：macOS / Windows / Linux（含这些系统上的浏览器）为键盘，其他为触屏。游戏中按下任意键盘按键切到键盘模式；触碰任一触屏按钮切回触屏模式。
- **当关技能**：`GameConstants.heroSkillForLevel(世界, 关)`，即现有右下角技能键默认的技能。
- **选中技能**：触屏技能键当前会放出的技能，开局等于当关技能。

## 4. 需求与验收标准

### R1 首页精简（8 → 6 个入口）
- 删除「iPhone 版」按钮及其弹窗。
- 删除底部「关于与上架说明」文字链接，「关于」移到设置页最下方。
- 保留：继续冒险、选关地图、糖果商店、玩法、任务、设置。

验收：首页找不到「iPhone 版」和「关于与上架说明」；上述 6 个入口都在。

### R2 关于页去掉开发者信息
- 删除 Android 上架、iPhone / Codemagic / docs/BUILD_IOS.md 这两段。
- 保留名称、版本、简介、隐私、适龄提示。

验收：关于页不含 `BUILD_IOS`、`Codemagic`、`apk`；仍含「隐私」。

### R3 技能入口合并（游戏页）
- **键盘模式**：右上技能条照旧显示 6 枚（J/K/Q/1/2/3），可点可按键。
- **触屏模式**：不显示右上技能条。右下技能大按钮旁边加一个小「换」按钮，每点一次按 闪冲→糖盾→花弹→下砸→二段→糖线→闪冲 的顺序切换选中技能；技能大按钮的文字、冷却进度和释放的技能都跟随选中技能。
- 键盘 J/K/Q/1/2/3 直接放对应技能，不改变选中技能。
- 每关开局，选中技能 = 当关技能。

验收：
- 新游戏的选中技能等于当关技能；切换 6 次回到原技能；切换后按钮文字变成新技能名。
- 无参数 `activateSkill()` 放出的是选中技能。
- 触屏模式下技能控件共 2 个（技能键 +「换」），在宽 320 的竖屏也不溢出。

### R4 去掉 HUD 左上返回键
- 游戏页左上角 ← 删除，退出关卡只走暂停菜单「退出选关」（仍弹确认框）。
- 暂停键保留。

验收：游戏页 HUD 不含返回图标；暂停菜单仍有「继续 / 重试本关 / 退出选关」。

### R5 「选关」一定去选关地图（Bug 修复）
- 进关时记录来源：从首页「继续冒险」进 = 来自首页；从选关地图进 = 来自地图。「下一关 / 下一世界 / 再来一局 / 重试本关」沿用原来源。
- 过关弹窗「选关」、确认退出：来自地图 → 返回地图；来自首页 → 用当前世界的选关地图替换游戏页。
- 选关地图支持指定打开的世界，默认仍是第 1 个世界。

验收：来自首页时，「选关」动作是“替换为地图”；来自地图时是“返回”。`WorldMapPage(initialWorld: 3)` 打开时选中第 4 个世界。

### R6 音量开关并入滑块
- 删除「操作音效」「背景音乐」两个开关，只留「音效音量」「音乐音量」滑块。
- 滑块显示值：开关为关时显示 0，否则显示音量。（老存档里开关为关的玩家，看到的是 0。）
- 拖动滑块：音量 = 新值；开关 = 新值 > 0。
- 音乐滑块从 >0 拖到 0 时停 BGM，从 0 拖到 >0 时恢复 BGM。

验收：设置页没有这两个开关；存档 `sound_on=false, sound_volume=0.8` 时音效滑块显示 0；拖到 0 后存档 `sound_on=false`，拖到 0.5 后 `sound_on=true, sound_volume=0.5`。

### R7 帧率只在 Android 显示
- 「帧率」小节只在 Android（非网页）显示。

验收：平台为 iOS 时设置页没有「帧率」；Android 时有。

### R8 商店「穿戴中」不可点
- 已穿戴的商品按钮置为禁用（`onPressed == null`），文字仍为「穿戴中」。

验收：默认外观那一行的按钮 `onPressed` 为空。

### R9 说明文字按输入模式显示，且只写一份
- 新手教程、暂停菜单按当前输入模式显示触屏或键盘说明。
- 玩法页「操作」卡片同时列出触屏和键盘两套。
- 三处文字来自同一处常量，不再各写各的。触屏说明要提到「换」按钮；键盘说明要包含 F 射击、Esc/P 暂停。

验收：触屏说明含「换」；键盘说明含「F」和「Esc」；玩法页同时包含两套说明的第一行。

### R10 清理
- 删除没人调用的 `MacaronGame.tapJump()`。

## 5. 数量对比

| 位置 | 改前 | 改后 |
|---|---|---|
| 首页入口 | 8 | 6 |
| 游戏页常驻（触屏） | 14 | 8（← → 蹲 跑 技能 换 跳 + 暂停，射击按需） |
| 设置页可操作控件 | 16 | 15（Android）/ 11（其他平台），含新增「关于」 |

## 6. 风险

- 触屏玩家要先点「换」才能用非当关技能，比原来点右上芯片多一步。好处是按钮都在右手拇指区。若试玩反馈不好，后续可改为长按技能键弹出轮盘。
- 老存档里关了开关、音量还在的玩家，升级后滑块显示 0，拖动后才恢复，符合预期。
