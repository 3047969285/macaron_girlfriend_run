# 字体覆盖与 HUD 标题可读性

## 背景（来自网页版试玩报告）

- HUD 和关卡预览里出现豆腐块：例如“白马疾行”“归路指引”。包内的 `NotoSansSC` 是子集字体，新加的文案用了子集里没有的字，网页版用了 `--no-web-resources-cdn`，回退字体 404，于是显示成方块。
- 左上的世界名、关名在深色或花纹背景上几乎看不清。

## 需求

- **F1 字体覆盖**：`lib/` 下所有 Dart 字符串字面量里出现的汉字（U+4E00–U+9FFF）和常用中文标点，必须同时存在于 `assets/fonts/NotoSansSC-Regular.ttf` 和 `NotoSansSC-Bold.ttf` 的字符映射表里。缺字的处理方式：**改文案**，换成字体里已有的同义字或词，保持原意；不动字体文件（没有完整的 Noto 源字体可重新裁剪）。缺字太多（超过 40 个不同的字）时停下来报告缺字清单。
- **F2 标题可读**：游戏页左上的世界名、关名、难度三行文字放进半透明圆角底板（白色透明度 0.6，圆角 10，内边距横 8 竖 4），文字用深色（`MacaronColors.cocoa`），不再直接压在场景上。新增公开组件 `GameHudTitle`（`lib/ui/play_page.dart`，参数 `worldName`、`levelTitle`、`difficulty`）。

## 验收

- `test/font_coverage_test.dart`：用纯 Dart 解析两个 TTF 的 cmap（格式 4 和 12），扫描 `lib/**/*.dart` 的字符串字面量，断言所有汉字和中文标点都被覆盖；失败信息列出缺字和所在文件。测试要读真实文件，不写死字表。
- `test/mobile_hud_test.dart` 增加一条：`GameHudTitle` 的三行文字外层有 `DecoratedBox`，颜色透明度 ≥ 0.55，且文字颜色是 `MacaronColors.cocoa`。
- 全套测试和 `dart analyze lib test` 通过。

## 不做

不改字体文件，不改 `--no-web-resources-cdn` 的构建方式，不改玩法和关卡。
