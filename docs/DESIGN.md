# 马卡龙女友跑酷（Macaron Girlfriend Run）设计说明

> 日期：2026-08-08  
> 状态：一期最好玩完整版（方案 D 全能第二轮）；联机不做

## 目标

- Flutter 跨端（Android + iOS），桌面独立工程
- 可爱甜妹风、马卡龙色、低多边形卡通 + ≤3 层视差
- 左方向键 + 右跳/跑，难度中等
- 全手作结构：9 世界 × 11 关 = 99 关
- 按设备适配最高 120Hz；中端可降 60
- 无服务器；联机仅预留角色枚举，不实现网络

## 技术栈

- Flutter 3.35+ / Dart 3.9+
- Flame 游戏循环
- shared_preferences 本地存档
- 自研 AABB 瓦片碰撞（控内存，不用重型物理引擎）

## 架构

`UI（菜单/选关/设置）→ MacaronGame（Flame）→ 输入/玩家/关卡/实体/相机 → SaveService`

## 性能闸门

- 视差最多 3 层
- 同时活跃敌人/道具上限
- 切关卸载实体
- `display.refreshRate` 适配，设置可锁 60/90/120/自适应
