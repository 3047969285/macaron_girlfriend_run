# 下一步优化

日期：2026-10-16。对照当前工作区代码；本地未提交改动不能视为已经在线上发布。

碰撞继续用现在的 AABB，不换 Forge2D，也不上 Rive。每一步做完都跑全套 `flutter test`，不加 `--name`。

## 已经在代码里的

- 六技能：J 闪冲、K 糖盾、Q 花弹、1 下砸、2 二段、3 糖线。
- 非 Boss 关各有一座单向台 `U`、碎裂台 `X`、水平移动台 `O`；每三关另有垂直移动台 `I`。垂直台行程不进入地面路线，站立玩家随台升降。
- 九个世界都有自己的地表和路边摆件。糖壳 `L`、滚轮 `Y`、糖泡 `J` 已进入每个世界的非 Boss 关，包括每世界第 1、3、10 关；没有安全空位时才替换普通巡逻怪。
- 普通关按世界轮换包内三首 Kevin MacLeod 授权曲；Boss 关使用每世界独立 4 小节原创短曲。普通关音频不可用时回退到 `SynthWav` 的 16 小节分段变奏循环；按世界与曲型缓存合成曲。
- 人物由 `GirlfriendPlayer` 用 `Canvas` 绘制；待机呼吸、跑步、上升、下落与下砸已有独立姿态，且绘制不改碰撞尺寸和脚底锚点。

## 已完成

- 每个世界第 1、3、10 关加入糖壳、滚轮、糖泡，Boss 关保持瞄准跑道。90 个普通关现在全部保留真实敌人，通过正常移动、跳跃、下蹲、射击与技能输入通关；9 个 Boss 关也保留沿途小怪，验证取枪、进场、战斗和到达出口。地形独立验证仍覆盖 99 关。
- 糖泡蓄力弹起后落地发出双向低矮糖波，起跳和无敌技能可反制。糖波分段检查地形，遇坑或墙消散，距离和数量有上限；覆盖落地触发、实战受击、跳跃回避和死亡清理。
- 触控主技能按钮随关卡切换名称、能力和独立冷却，六种关卡主技能均有行为验证。
- 植物伙伴瞄准怪物身体，选择视线内目标；墙体和缩壳糖壳会挡住射线，等待出现有效攻击路径后再射击。Boss 只在弹丸来得及命中的远程反击窗口成为目标。头部植物跟随出手方向转向，并有短暂后坐和豆粒闪光，碰撞尺寸不变；行为和渲染均有回归测试。
- 载具支持“跑＋蹲”制动蓄力、松蹲短时加速，再次下蹲取消加速；松方向键仍然停车，空中沿用原移动速度，不改变基础跳跃距离。车轮随实际速度转动，车身增加明暗层次和加速拖线，HUD 只显示简短蓄力百分比和加速状态；覆盖蓄力、取消、空中、到期与受击清理。
- 九个世界的悬空平台采用独立材质：草皮威化、草莓夹心、汽水玻璃、星晶、木栈道、城堡石材、峡谷岩层、焦糖支架和彩虹云层。宽平台和单格台均保持原有碰撞矩形、清晰顶边和 Picture 缓存；增加九套材质及缓存前后像素一致性验证。
- Web 入口按构建标识为主程序增加版本参数，引导脚本每次访问检查更新；标识请求超时、缺失或异常时仍启动游戏，不清空本地存档。版本选择的四种分支及真实浏览器启动已验证。
- 人物增加待机、跑步、上升、下落和下砸姿态；渲染测试逐帧比对画面，并确认碰撞盒维持原尺寸。
- 每三关加入独立 `I` 垂直升降台；补齐上下承载与从下穿过的单向碰撞，生成时避开轨道内的实心块。全套测试覆盖 99 关的保证路线。
- 第 1 关将 `U→X→O` 排到开场前段，按实际可用空位递进布置；加入顺序与前段距离回归测试。
- 普通关主音乐改为播放包内已署名的授权曲并按世界轮换；Boss 关使用九段独立 4 小节原创主题。普通关故障回退循环扩为 16 小节，后半换和弦与旋律，并以 `Float32List` 降低生成工作缓冲。
