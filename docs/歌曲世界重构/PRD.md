# 歌曲世界整体重构

## 产品需求说明书

六首歌各有完整的视觉和玩法身份，覆盖背景远景、上下层地形、收集物、敌人、首领和角色体验；不以路牌或颜色变化充当世界设计。既有歌曲映射与顺序不变。每首歌的场景是对歌词意象的创作，不声称实时逐句同步。

- 素颜：校园、街道和回忆中的恋爱世界；收集信物，面对疏离、误会等意象的敌人。
- 身骑白马：关隘、旷野和归途；玩家骑白马穿越世界，低矮空间可安全通过。
- 谁：镜面、倒影与距离，收集寻找答案的碎片，敌人与镜像主题呼应。
- 静悄悄：夜色、花园与心跳，收集心意，敌人与夜间花园呼应。
- 5点20AM：清晨城市与时钟，收集时间印记，敌人与钟表街景呼应。
- Lost：夜路、岔道与远方灯光，收集指引，敌人与迷途夜影呼应。

保留地面坑位、已验证的基础通关路径及存档进度；世界装饰不能伪装成实体障碍或遮挡实际危险。角色、敌人、奖励的真实行为和呈现必须一致，性能保持可玩。现有基础通关机器人必须通过。

## 接口文档

世界主题由世界到歌曲的既有映射确定；存档、关卡数据与音乐接口保持兼容。新增主题参数仅用于游戏内部组件，不要求迁移存档。

## 测试

遍历六首歌及映射世界，检查主题组件、奖励与敌人确实接入实际关卡；验证骑乘的控制、跳跃和低矮空间；检查主题渲染差异、确定性和既有碰撞。运行全套 Flutter 测试与静态分析。

## 世界收集机制

每收集 8 个当前歌曲的信物触发一次世界能力，计数在界面展示：素颜获得短暂守护；白马刷新闪冲；谁刷新护盾；静悄悄短时吸引附近花瓣；5点20AM 恢复 2 秒（不超过关卡时间上限）；Lost 刷新糖线。收集量仍计入原有进度和钱包，不更改存档。白马骑乘保留原有移动与跳跃速度，按下蹲通过低顶；载具或飞行道具生效时暂时切换到对应状态。

## 实现边界

六首歌各有完整远景、地表和平台材质、信物、敌人与首领造型及收集能力；白马世界带骑乘图像及骑乘状态。主题敌人沿用原有巡逻、弹跳、飞行与首领攻击规则，并非六套全新 AI。额外上层路线只在通过占位与可达校验时采用；《谁》和《5点20AM》的塔楼受现有尺寸和通关约束限制，暂不放本轮加宽分支。此前明确停止的地面坑节奏改造没有恢复。
