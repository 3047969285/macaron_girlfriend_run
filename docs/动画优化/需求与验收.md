# 动画优化需求与验收

## 产品需求说明书

1. 主角过渡使用玩家实例的游戏时间；非跑步姿势过渡时旧帧不透明、新帧按比例覆盖，过渡时长 140 毫秒，不同玩家互不影响。涉及跑步的切换只画当前帧，避免出现双重轮廓；`animation_polish_test.dart` 检查绘制层和实例隔离。
2. 跑步每移动 96 游戏单位完成四帧循环，运行周期误差不超过 0.001；闲置呼吸缩放保持 0.985～1.015。`animation_polish_test.dart` 检查位移、呼吸及不同帧率结果。
3. 匀速运动的主角和镜头逐帧横向位移方差，在 30、60、120 FPS 稳态下均低于 0.01 平方像素；由无头游戏测试测量，保持现有物理与碰撞结果。
4. 敌人走动、跳怪着陆、死亡动画以及糖果、旗帜、弹簧的视觉变化均有界；死亡消散不超过 0.3 秒且死亡后不参与碰撞。组件测试验证对应进度与结束状态。
5. 通关弹窗按 100 毫秒间隔逐段出现，分数在 800 毫秒内滚动到目标值；世界切换和可选关卡按压有动态反馈。组件测试验证时间和交互。
6. 粒子不超过既有粒子上限，环、文字和光束各不超过 32 个并复用；相关测试覆盖容量和复用。

## 接口文档

不新增外部接口；游戏输入、存档、关卡及碰撞接口保持不变。

## 测试

运行 `flutter test` 全套和 `dart analyze lib test`，另在无头测试测量各帧率下的横向位移方差。

## 物理步长评估

在首关移除敌人后，使用真实游戏更新、先加速 1 秒再采样约 1/3 秒，角色在 30、60、120 FPS 的横向位移方差均为 0，镜头分别为 0.001213、0.000358、0.000097 平方像素。另以非零匀速输入测试实际镜头跟随，方差均低于 0.000000003。现有画面坐标已保留亚像素精度；固定物理步长会改变现有时间截断、碰撞和关卡机器人行为，上述稳定场景不足以证明引入它有收益，因此保留现有物理步长和浮点坐标，不引入插值延迟。该测试不代表跳跃、碰撞或掉帧时的全部画面表现。
